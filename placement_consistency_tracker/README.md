# Placement Consistency Tracker

A long-term personal productivity and placement-preparation tracker built with plain HTML, CSS and JavaScript.

## Features

- Communication, Aptitude, Resume & Career, and Coding areas
- Custom daily hour targets
- Completion tracking for any date
- Long-term calendar history — not limited to 10 days
- Current streak and best streak
- Productive-day count
- Hours logged
- Analytics for 30, 90, 365 days or all recorded time
- Local browser storage using localStorage
- Export/import JSON backup
- Responsive design for desktop and mobile
- Motivational messages based on daily progress

## Run

No installation is required.

1. Extract the ZIP.
2. Open `index.html` in a browser.
3. Start recording your daily progress.

For VS Code, open the extracted folder and use Live Server if you have the extension installed.

## Important: Long-term data

The first version stores data in the browser's localStorage. This is intentionally simple and requires no backend.

For a serious multi-device version later, the project can be upgraded with:
- Firebase/Supabase authentication
- Cloud database
- User accounts
- Automatic cloud backup
- Multiple devices
- Advanced charts
- Monthly/yearly goals
- Skill-specific learning logs

Always use **Export backup** occasionally before clearing browser data or changing browsers.
